# Project Notes

The repository is divided by responsibility:

1. `hardware/ip` — custom RTL/IP source packages.
2. `hardware/vivado` — SoC integration and board constraints.
3. `software/vitis` — MicroBlaze V management firmware.
4. `software/stm32` — external Sender and Receiver firmware.

This structure is the reference used for subsequent Notion documentation and presentation work.
