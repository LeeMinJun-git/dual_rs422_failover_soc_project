# Vivado System Integration

Final Basys3 SoC integration sources for Vivado 2024.2.

- `project/`: original Vivado project descriptor
- `block_design/`: Block Design and IP instance configuration files
- `wrapper/`: generated top-level HDL wrapper
- `constraints/`: Basys3 board I/O constraints
- `export/`: final hardware XSA
- `results/`: selected final implementation evidence

Generated caches, `.runs` work products, simulation databases, and hardware-manager captures are intentionally excluded.
