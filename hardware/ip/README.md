# Custom IP

Each directory contains the final source package for one custom IP used in the integrated Basys3 SoC design.

- `redundant_link_core` — dual UART validation, channel health, failover/recovery, event FIFO, AXI4-Lite, and IRQ.
- `sensor_guard_ip` — selected ADC monitoring and alarm policy.
- `voltage_display_ip` — ADC-to-voltage conversion and FND display control.
